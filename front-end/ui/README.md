# Frontend Layer (.NET)

## الوصف التقني
تطبيق سطح المكتب أو الهاتف الذي يمثل واجهة المستخدم النهائية، خالٍ تماماً من منطق الأعمال.

## التقنيات المستخدمة
- **الإطار:** .NET (C#)
- **نوع التطبيق:** Windows Forms / WPF / MAUI
- **التواصل:** HTTP Client لاستهلاك RESTful API
- **نمط المعمارية:** MVVM / MVC

## المسؤوليات الأساسية
- عرض واجهات المستخدم (UI)
- إرسال طلبات HTTP إلى الباك إند (Laravel API)
- عرض الاستجابات للمستخدم
- إدارة الحالة المحلية للواجهات فقط

## ملاحظات هامة
- التطبيق لا يحتوي على أي منطق عمل (Business Logic)
- التطبيق لا يتواصل مباشرة مع قاعدة البيانات
- أي تعديل في المنطق يتم في الباك إند فقط ولا يتطلب إعادة تثبيت التطبيق
- التطبيق خفيف وسريع لأن العمليات الثقيلة تُنفذ على السيرفر
